01
CONNECT

配置模型与 API Key

界书自己不提供 AI，所有生成、润色、扮演都用你自己的模型账号。Key 只写在本机应用数据里，不会发往除你所选服务商之外的任何地方；界书也不收任何费用，你只需要向服务商按用量付费。

  1. 打开设置点左上角那个「界」字圆标，进入设置页，找到「接入模型管理」。
  2. 选服务商点 DeepSeek 或 通义千问 的卡片，接口地址会自动填好（应用会自动补上 /chat/completions）。用别家的模型也行：选任意卡片后手动改「接口地址」即可，只要对方是 OpenAI 兼容接口。
  3. 粘贴 Key点开默认折叠的「API Key」一栏，把以 sk- 开头的密钥粘进去；想核对可以点右侧「显示」。Key 只保存本机。
  4. 确认模型点「自动识别最新」让应用拉取你账号下可用的模型并自动选中；也可以手动填，例如 DeepSeek 的 deepseek-chat。
  5. 保存并测试点「保存配置」，再点「测试连接」。出现「连接成功」就说明通了；配置好以后，首页的按钮会亮起来，不再提示「未配置」。
Key 获取地址（复制到浏览器打开）

DeepSeek：platform.deepseek.com → 登录后点左侧「API keys」→「创建 API key」，复制 sk- 开头的那串。充值在「充值」页，几块钱就能用很久。

DeepSeek 的接口地址：填 https://api.deepseek.com 就好，不需要在末尾加 /v1；应用会自己接上 /chat/completions。

通义千问（阿里云百炼）：bailian.console.aliyun.com → 开通「百炼大模型服务」→ 右上角「API-KEY 管理」→ 创建并复制。接口地址用 https://dashscope.aliyuncs.com/compatible-mode/v1。

其他可选：OpenAI（platform.openai.com/api-keys）、Moonshot Kimi（platform.moonshot.cn/console/api-keys）、智谱 GLM（open.bigmodel.cn）、硅基流动（cloud.siliconflow.cn）、OpenRouter（openrouter.ai/keys）。它们大多是 OpenAI 兼容接口：DeepSeek 用 https://api.deepseek.com（不加 /v1），OpenAI 系的一般要写成 .../v1。

如果你只有网页版会员

网页版（如网页版 DeepSeek、Kimi 会员）不能当 API 用，必须在上面这些「开放平台 / 控制台」里单独申请 Key 并按量充值。界书不需要月度订阅，用多少算多少。

02
THE SHELF

世界观：书架与编辑器

首页就是你的书架。每个世界是一张卡片，卡片上写着它的地区、货币，以及 NPC 与规则的数量。所有修改都会自动保存在本机。

  • 新建点右上角的 ＋ 手写一个世界；也可以点「一句话生成世界观」写下「一座用记忆当货币的群岛」，让 AI 直接给出一整个草稿。左侧的「AI 导入」能把写好的 Word / 文本 / PDF 读成世界观（见第 05 章）。
  • 打开点任意卡片进入编辑页：世界名称、一句话概述、地区分类、货币制度，往下是「主要 NPC」与「基础规则」。底部一直显示「已保存」，改完直接返回就是保存。
  • AI 共写编辑页里的三个按钮：AI 填写只补空白、AI 优化润色已有文字、AI 扩展在当前内容后续写角色或规则。每次都会先问你确认，再写进去。
  • 导出编辑页右上角的导出图标可以把这一个世界存成 Word（纯文字设定，整篇发给 AI 就能开玩）或 JSON（结构化，可以再导入回来）。
  • 长按多选长按任意世界进入多选，可批量删除，也可以让 AI 把两个世界融合成一个。
  • 分组用组名右侧的「改名」给一组世界命名，点组名可折叠展开；没归组的世界落在「未分组」。
03
THE ELEMENTS

一个世界需要哪些元素

不必一次写完。先立住名称与规则，剩下的可以边写边长，也可以交给 AI 补。

  • 01
    世界名称 必填

    三五个字就够。它是这个世界的地基，会出现在卡片和列表里。

  • 02
    一句话概述 建议

    用一句话说清这个世界最特别的规则。AI 扮演时最依赖这一句。

  • 03
    地区分类

    城市、群岛、门派、星区都行。它会显示在卡片第二行，方便你一眼分辨。

  • 04
    货币制度

    写清「什么能换什么」。开始一段对话时，还可以在货币面板里定多级货币与汇率。

  • 05
    主要 NPC

    可以手写，也可以点「从人设库挑选」把已经写好的角色整份带进来（外貌、性格、能力、过往都会带过去）。

  • 06
    基础规则

    世界的物理与禁忌：魔法要付出代价、夜里不能照镜子。它们不解释原因，却约束一切。

规则灯塔只在浓雾里点亮；航路一旦被记起，就会有人失去它。

04
THE CAST

人设库

底部导航中间的「人设」是你的人物库，分两类：用户人设（你自己）和 NPC 人设（故事里的人）。点右上角的 ＋ 新建，点卡片进编辑页。

  • 字段名称、性别（男 / 女 / 双 / 无性）、身高、体重、年龄、外貌描写、性格特点、身材特点、内心（愿望或执念）、过去人生的重要经历。除了名称，都可以先空着。
  • 特殊能力在「身体数据」下面，12 个预设胶囊（念力、元素掌控、治愈、读心、预言、变形、通灵、瞬移、时间停滞、记忆读取、机械改造、无能力）点一下即选中，再点取消；也可以自己写一条，最多 8 条。
  • AI 共写人设编辑页同样有 AI 卡片：写一句「雨夜旧书店的老板，能听见书里留下的记忆」点「生成」，AI 会把整份人设填好；「AI 填写 / 优化 / 扩展」与世界观页一致。
  • 用起来在世界编辑页点「从人设库挑选」，选中的角色会带着完整设定成为该世界的 NPC；开始对话时也可以直接选一个人设来扮演。
  • 导出人设页右上角的保存按钮可以把整个人设库导出成 Word 或 JSON（分「用户人设 / NPC 人设」两个小节，含特殊能力与各段设定）。
  • 删除编辑页右上角可以删除这一个人设，会二次确认；已经进入世界的 NPC 不会被连带删除。
05
THE CHAT

对话：让 AI 演给你看

底部导航的「对话」是 AI 陪你演故事的地方。开局只需两步：选一组角色，点开始。

  • 两种开局世界观 × 用户人设：AI 当 DM，读整个世界（概述、地区、货币、NPC、规则）来演。用户人设 × NPC：AI 只演那一位 NPC，你就是你的用户人设，AI 不会跳出角色说话。
  • 动作怎么写用中文圆括号写动作，例如「（我推门进来）今晚不走了吧。」AI 会照同样的方式用（）写它的动作；括号外是说的话。
  • 货币新建时可以自己定：主货币（元 / 记忆 / 金币），再加任意多种「其它货币」，每一种填「1 单位 = 折合多少主货币」，例如金币 100、银币 10。余额永远按主货币记，AI 会按你的汇率算账。
  • 人物状态可以打开「显示人物状态」，默认带生命值、精神值，可以增删任意条目（体力、理智、声望、好感……）。AI 每回合都会考虑这些数值：生命值过低会描写伤口与站不稳，精神值过低会写恍惚与错觉，数值高则写体力充沛、神志清明。它只在自己确实造成变化时才改数，并注明原因。
  • 看状态对话右上角的 ⓘ 按钮打开「当前状态」面板，能看到货币、汇率与所有数值；点「修改数值」可以手动改。
  • 发图片 / 文件输入栏右侧的 ＋ 打开菜单：发送图片（需要先在对话设置里选一个识图模型，否则应用会提示「当前模型看不了图片」）、发送文件（txt / md 等纯文本设定）、保存这组对话、对话设置、清空记录。
  • 对话设置在 ⋯ 菜单里进入：选对话用哪个模型、识图用哪个模型、每段回复的最少字数（0 表示不限制）。API Key 与接口地址自动沿用你在设置页配好的那份，不用再填一次。
  • 重新生成 / 编辑重发AI 回复下方有「重新生成」，会让它换一个角度重写这一轮；点自己发过的消息可以改字，改完点「重发」，AI 会按改过的内容重新回应。
  • 整理对话列表长按任意一条进入多选，可以归为一组或批量删除；列表右上角的保存按钮导出全部对话，单个对话的 ⋯ 菜单里可以只保存这一组（都是 Word 或 JSON）。
06
BACKUP & IMPORT

备份、导出与 AI 导入

所有数据都在本机。换手机、重装应用之前，先导出一份备份。

  • 保存到文件首页顶部的备份按钮 →「保存到文件」，把全部世界观、人设、对话、分组导出成一个 JSON 备份；「从文件导入」会按 id 合并进来，已存在的不会被覆盖或删除。
  • 只保存一部分同一个面板里还有「只保存人设」「只保存世界观」「只保存对话」，各自可以导出 Word 或 JSON，适合单独分享或存档。
  • 要不要带 API Key面板底部有开关，默认不带。只有在自己的设备之间迁移时才建议打开；发给别人时一定保持关闭。
  • AI 导入首页「一句话生成世界观」下面的「AI 导入」：选「导入为世界观」或「导入为人设」，再挑文件（.docx / .txt / .md / .pdf）。应用会先在本机抽出文字，再让 AI 按原文整理成对应结构——只照抄，不新增、不润色：文件里没写的字段会留空，不会替你编一个年龄。
  • PDF 注意能够读取带文字层的 PDF；扫描件、图片版 PDF 读不出文字时会提示你换成 Word 或文本。
07
TROUBLESHOOTING

常见问题

  • 测试连接失败，提示 401 / 403Key 不对或已失效：回控制台重新复制一次，注意不要带空格和换行。
  • 提示 402 / 余额不足账号没充值或额度用完，去服务商控制台充值后再试。
  • 提示 404 / 模型不存在模型名写错了，或者接口地址的 /v1 多写/少写了——DeepSeek 不加 /v1，OpenAI 兼容的一般要加。可以点「自动识别最新」让应用自己填。
  • 提示 429请求太频繁或并发超限，等几十秒再点。
  • AI 一直转圈或超时检查网络（部分服务商需要能访问境外网络），或换一个更小的模型试试。
  • 发图片 AI 说看不了在「对话设置 → 识图模型」里选一个支持视觉的模型（如通义千问的 vl 系列）；不选时应用只会发文字。
  • AI 返回的内容不是有效设定多半是模型不擅长输出纯 JSON。现在应用会自动重试一次、并在实在解析不了时把原文整理成一份可编辑的设定，不再直接失败；换一个更强的模型（如 deepseek-chat）成功率更高。
  • 导入的文件太长正文超过约 12000 字会被截断（取前面的部分），可以先在 Word 里拆分再导入。
  • 数据会丢吗默认保存在本机应用数据里，卸载应用会一起清掉。养成导出备份的习惯，换机时用「从文件导入」恢复。
